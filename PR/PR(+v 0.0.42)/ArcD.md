# ArcD v0.0.42

Explorer context menu uses a file/folder header, three grouped action sections, semantic menuitem buttons, keyboard up/down/home/end navigation, and theme-aware styling. Menu placement uses measured dimensions and panel bounds. Explorer tree scroll, wheel and touchmove dismiss the menu, even when wheel starts at a scroll boundary. Existing click-away and Escape dismissal are retained. Menu closes on Explorer hide and locale change. Action implementations are unchanged.
